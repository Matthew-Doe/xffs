# Durable COW batching USB results — 2026-10-02

The 64 KiB default passes both performance acceptance criteria, with unchanged
seven-barrier durability. Three repetitions of 8 MiB creation and overwrite ran
at each of 4, 16, 64 and 256 KiB on the existing 116.1 GiB USB filesystem, serial
`0085199340190280`. No physical device was formatted or unplugged.

Each repetition rotated the order: 4/16/64/256, 16/64/256/4, then 64/256/4/16.
All twelve runs passed content verification, post-unmount filesystem checks,
cleanup, and restored free-space accounting. The baseline and optimized runs
used the same release binary; only the batch setting changed.

## Medians

| Batch KiB | Create seconds | Overwrite seconds | Create / overwrite MiB/s | Create / overwrite flushes | Data batches per phase |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 4 | 52.249 | 52.293 | 0.153 / 0.153 | 14,403 / 14,396 | 2,056 |
| 16 | 8.723 | 22.191 | 0.917 / 0.361 | 3,651 / 3,644 | 520 |
| 64 | 3.182 | 2.376 | 2.514 / 3.367 | 963 / 956 | 136 |
| 256 | 0.744 | 0.840 | 10.747 / 9.520 | 291 / 284 | 40 |

Relative to 4 KiB, the 64 KiB default improved median creation elapsed time by
16.42× and overwrite by 22.01×. Total profiler flushes fell by 93.31% and 93.36%,
respectively, exceeding the required 90%. The core's aligned 1 MiB tests separately
assert 16 data transactions / 112 flushes at 64 KiB versus 256 / 1,792 at 4 KiB:
exactly 16× fewer data-transaction flushes.

The FUSE workload made 16 core requests per phase and extra partial batches at
request boundaries, hence 136 data batches at 64 KiB rather than the aligned
8 MiB ideal of 128. Metadata-only commits and explicit syncs are included in the
profiler's total flush count. All phases committed exactly 8,388,608 user bytes.

Timing varies: the 64 KiB overwrite samples were 2.330, 13.167 and 2.376 seconds.
In the slower sample, backend flushes consumed 12.951 seconds, including 4.703
seconds in checkpoint flushes; metadata staging remained about 0.011 seconds.
The retained phase timings show that this variation remains concentrated in
synchronous storage I/O. Medians include every repetition. The 256 KiB setting
was faster in this experiment; it remains a tuning option and the agreed default
stays 64 KiB. These are measurements of this device and workload.
